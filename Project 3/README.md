## Summary
Digital SafeLock Simulator is an interactive safe prototype that mimics the functionality of a real safe without the actual physical mechanism and breakproof box. The safe has a menu that has the following functions: unlock/lock, back to menu, change password, and show date.

## Reflection
At the start of this project, I had trouble completing the functions. I didn't yet have an understanding of using C; I intend to use pointers, a very foreign concept to me, but I need to find how to do so. After taking an edX program (C Programming with Linux), I learned all the necessary concepts and resumed my progress on this project one step at a time - adding functions or debugging old/new problems. All the code you see has been written by me, not an AI. Making a mistakes is what a beginner should do to become more familiar and aware of what they are using in their projects. AI replaces creativity with superficial progress.
