# Smart Rock, Paper, Scissors Game
Siddharth Sivakumar (@siddharthsvkm)

July 12, 2026

Emulated using Wokwi

Project URL: https://wokwi.com/projects/470567923075776513

## Summary
This project is a rps game against the computer. The computer makes "random" moves, so it is indeed random whether you will win or not. The randomness depends on the amount of electrical noise that is sensed by one of the analog pins.

## Used Components:
- 1x MEGA Controller Board
- 1x Joystick
- 1x LCD (16x2)
- 2x RGB LED
- 4x LED (Purple, Red, Blue, Green)
- 1x Potentiometer
- 10x 220Ω Resistors
- 1x 10kΩ Resistor
- 37x Jumper Wires
